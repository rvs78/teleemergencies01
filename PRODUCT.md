# Product

## Platform

web (ordinador de l'aula i casa; també mòbil i tauleta)

## Users

Alumnat del CFGM Emergències Sanitàries (MP0060 Teleemergències, grup TES 1AA, Institut d'FP Sanitària Vall d'Hebron, Catalunya), adults joves de 16-25 anys. Treball individual. El professorat (especialitat 518, Processos Sanitaris) revisa el PDF que l'alumnat lliura a Google Classroom.

## Product Purpose

Aprendre de forma gràfica i progressiva el CODI 3 (codificació pròpia del SEM, document U100.U00.0.D6.008, versió modificada 23/09/2021) i el codi INTERCO (alfabet fonètic internacional) que es fan servir a la radiocomunicació entre CECOS i les unitats del SEM. Complementa la pràctica de radiocomunicació per parelles feta a classe (guions Bravo 727).

## Capabilities and Constraints

- Web estàtica (GitHub Pages), HTML, CSS i JavaScript sense compilació; jsPDF per a l'informe.
- Accés: correu @isvh.cat + contrasenya d'aula (empremta SHA-256). Barrera d'entrada, no autenticació. Progrés al localStorage.
- 6 fases progressives (1000 punts): INTERCO, famílies de codis, escenes il·lustrades, línia del servei, descodifica, simulador de ràdio.
- Il·lustracions generades amb IA (Seedream 5.5) i veus de CECOS generades amb IA (HeyGen Voice, Nadine i Lucian alternats), totes pre-generades: cap clau d'API al client.
- Informe PDF amb nota 1-10, punts per fase, errors, ajudes, codis a repassar i codi de verificació, per lliurar a Classroom.

## Product Principles

1. El codi oficial mana: només CODI 3 MODIFICAT, sense improvisar codis.
2. De recordar a transferir: cada fase demana un pas més (Bloom) i retira ajudes.
3. Feedback immediat i explicat: cada error ensenya el codi correcte i per què.
4. Professional i sobri: estètica de consola de coordinació, no de joc infantil; temes sensibles (3.31, 3.71, 3.62) amb respecte.
5. Accessible: tot el que s'escolta també es llegeix; teclat complet; contrast AA.
